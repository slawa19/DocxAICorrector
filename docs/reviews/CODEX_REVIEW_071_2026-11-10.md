## Находки

### 1. P2 — буквальный `#` в абзаце тела превращается в заголовок

`rebuild_block_with_narration_texts` восстанавливает префикс исключительно по тексту источника. `structural_roles` при этом не проверяются. Обычный абзац DOCX с текстом `# This hash introduces an ordinary comment in the example.` сохраняет роли `body/body` и `heading_level=None`, но после прохода получает Markdown-заголовок.

Самостоятельное debug-only вычисление на функциях из base и head подтвердило изменение. На base доставляется текст без `#`, на head — с `#`. Результат одинаков для обычной доставки и `source_fallback=True`. В сборке такой самостоятельный абзац сохраняет префикс, который Pandoc интерпретирует как заголовок.

**Частота** — воспроизведено на синтетическом входе. Среди 1591 исходного абзаца трёх входов FR-009 совпадений не обнаружено. Частота на других документах неизвестна. **Уверенность высокая.**

Нужна проверка структурного сигнала при восстановлении префикса и контртест с исходным `body`, начинающимся с `#`. Нынешний отрицательный пример содержит обычную прозу без этого пограничного условия.
