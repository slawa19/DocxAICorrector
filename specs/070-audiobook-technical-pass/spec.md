## Решения владельца (2026-11-09)

- **D-1. Аудиокнига — технический проход по уже готовому тексту.** Вход — переведённый и вычитанный пользователем
  документ (обычно результат перевода или редактуры). Режим не переводит, не выбирает языки и не редактирует стиль:
  только готовит текст для чтения вслух на том языке, на котором он написан. Селекторов «Целевой язык» и «Язык
  оригинала» в режиме нет.
- **D-2. Опция «подготовить текст для ElevenLabs» убирается из перевода (и редактуры).** Перевод с озвучкой без
  ручной проверки перевода смысла не имеет; второй проход и его ось конфигурации удаляются целиком, без
  совместимых псевдонимов (правило владельца 2026-11-08 «убирать мёртвые оси»).
- **D-3. Теги интонации ElevenLabs убираются.** Ни обязательных, ни необязательных: паузы — абзацами.
- **D-4. Числа пишутся словами, спецсимволы и эмодзи, которые могут быть озвучены, убираются.**
- **D-5. Исправить пять групп находок ревью** (`REVIEW.md`, план top-5): мусор начала книги, оглавление, указатель
  и таблицы в озвучке; HTML; противоречие промптов; тихие потери; проверка результата, которая не видит реального
  остатка.

## User Scenarios & Testing *(mandatory)*

### User Story 1 — Пользователь озвучивает готовый перевод (Priority: P1)

Пользователь перевёл книгу, вычитал результат, загрузил полученный DOCX и выбрал «Подготовка аудиокниги». Языков
выбирать не нужно. На выходе — текст, который можно отдать в ElevenLabs без ручной чистки: без мусора титульных
страниц, оглавления, указателя, таблиц, разметки, тегов, цифр и символов; каждый абзац основного текста на месте.

**Acceptance Scenarios**:

1. **Given** переведённая книга с титулом, оглавлением, примечаниями и указателем, **When** режим аудиокниги, **Then**
   в тексте нет абзацев этих регионов, а каждый абзац основного текста присутствует.
2. **Given** абзац «В 2007 году около 93 % семей…», **When** режим аудиокниги, **Then** в тексте «В две тысячи седьмом
   году около девяноста трёх процентов семей…» — числа словами в правильной форме, символа нет.
3. **Given** абзац с эмодзи, стрелкой, звёздочкой или `<sup>` из DOCX, **When** режим аудиокниги, **Then** этих
   знаков в тексте нет.

### User Story 2 — В переводе нет опции озвучки (Priority: P1)

Пользователь в режиме «Перевод» или «Редактура» не видит флажка «подготовить текст для ElevenLabs»; результат этих
режимов — только документ.

### Edge Cases

- Вход на любом языке: режим работает на языке текста и ничего не переводит; английский документ даёт английский
  текст для озвучки.
- Абзац, который модель вернула без изменений (`source_restored` в терминах конвейера), — это правильный текст книги
  и озвучивается.
- Абзац, где после проверки и одного исправления остались цифры или символы, доставляется и помечается для
  проверки с адресом; доставка не блокируется.
- Документ без регионов (короткий текст без титула и указателя) — озвучивается целиком.

## Requirements *(mandatory)*

- **FR-001 Режим без языков (D-1).** В режиме `audiobook` UI не показывает селекторы языков; конфиг, профиль
  прогона и раннер не требуют и не передают пару языков для этой операции; промпт говорит «язык текста», а не
  `{source_language}`/`{target_language}`. Операция перестаёт быть меняющей язык (`core/models.py:37`): удержание
  абзацев, глоссарий, контекст книги и все проверки «непереведённого текста» к ней не применяются. Абзац со
  статусом `source_restored` озвучивается. Профиль `ui-parity-standalone-audiobook` (`corpus_registry.toml`)
  переписывается без пары языков, его вход — переведённый документ.
- **FR-002 Удалить второй проход (D-2).** Удаляются: флажок в UI перевода и редактуры (`ui/_ui.py:757-763`), ключ
  `audiobook_postprocess_default`, поле профиля `audiobook_postprocess_enabled`, состояние и проводка
  (`runtime/state.py`, `processing/processing_runtime.py`, `pipeline/late_phases.py`, `ui/_app.py`,
  `validation/profiles.py`, `core/config*.py`), функции второго прохода в `pipeline/narration_postprocess.py`
  (`:281-533`), профиль `ui-parity-translate-audiobook-postprocess`, события `audiobook_postprocess_*` в
  `docs/LOGGING_AND_ARTIFACT_RETENTION.md` и `scripts/_list_log_events.py`, строки локалей, тесты второго прохода.
  Без псевдонимов: старый ключ в пользовательском `config.toml` даёт обычный WARNING `config_key_ignored`.
  Перевод и редактура больше не пишут `.tts.txt`.
- **FR-003 Что не звучит — решается по абзацу (D-5).** Проекция озвучки исключает абзацы: региона `front_matter`
  (кроме заголовка книги — роль заголовка/названия известна до проекции), роли оглавления, региона указателя и
  справочного аппарата (как сейчас по региону, но по абзацу, а не «весь блок»), роли таблицы, подписи к рисунку и
  таблице, картинки. Каждое исключение учитывается счётчиком по причине с адресами абзацев (как в spec 054).
- **FR-004 Непротиворечивый промпт (D-5).** Для `audiobook` — свой системный шаблон без правил «сохраняйте Markdown,
  списки, HTML-таблицы»; маркеры абзацев разрешены явно; для абзаца, который не нужно читать вслух, есть законный
  ход — пустой текст под его маркером, без повтора запроса. Интенсивность редактуры к промпту не добавляется.
  Промпт режима переписывается коротко и только по-русски (без смеси с английским жаргоном), без тегов, по
  принципам: читать вслух на языке текста; не пересказывать и не сокращать; адаптировать только то, что трудно
  понять на слух; числа, даты, годы, диапазоны, проценты, денежные суммы, римские цифры и номера пунктов —
  словами в правильной грамматической форме; сокращения и инициалы — раскрыть; символы — словами или убрать;
  ссылки на рисунки, таблицы, страницы и сноски — убрать; заголовки, набранные заглавными, — обычным регистром
  (аббревиатуры как есть); «ё» — там, где без неё меняется смысл или произношение. Примеры — одноязычные, на
  языке текста.
- **FR-005 Детерминированная чистка (D-3, D-4, D-5).** После модели и до сборки: удаляются HTML-теги; эмодзи и
  декоративные символы — по классу Unicode (пиктограммы, дингбаты, стрелки, геометрические фигуры, «прочие
  символы»), не по списку; любые фрагменты формы тега в квадратных скобках; маркеры списка-глифа (как сейчас).
  Цифровой маркер нумерованного списка кодом больше не срезается (его переписывает модель по FR-004). Знаки,
  несущие смысл (`%`, валюта, `№`, `§`, математические), кодом не удаляются — их переписывает модель, остаток
  ловит FR-006.
- **FR-006 Проверка остатка и одно исправление (D-4).** Детектор остатка по форме на каждом абзаце озвучки:
  цифры, надстрочные цифры, знаки валют и математики, `%`, `№`, `§`, HTML, URL и доменные имена, строки целиком
  заглавными из двух и более слов. Абзацы блока с остатком отправляются ОДНИМ дополнительным запросом с узкой
  инструкцией (переписать только этот остаток, остальное не трогать); проверка структуры ответа — как у основного
  запроса. Остаток после исправления — данные проверки (`needs_review`, адрес абзаца, образец), доставка не
  блокируется. Мёртвые правила обзора (`internal_placeholder`, `raw_url`, `markdown_heading`) удаляются; счётчик
  правила — число вхождений, а не уникальных значений.
- **FR-007 Сохранность текста.** Каждый озвучиваемый абзац входа присутствует в выходе: проверка покрытия по форме
  (доля длинных слов абзаца, найденных в его ответе) на каждом абзаце; недостача — данные проверки с адресом.
  Склейка абзацев недопустима: число абзацев ответа под маркерами равно числу отправленных.
- **FR-008 Замер (платный, после кода; ≈ 1 $, сумму подтверждает владелец).** Режим `audiobook` через канонический
  раннер на переведённых документах: главы bake-off (RM гл. 3, Money гл. III — переводы варианта A лежат в
  `D:\Temp\docxai-research\069-bakeoff\sources\*_pass1_A.docx`) и одна полная переведённая книга FR-008 спеки 069
  (Money, «Стандарт»). Метрики: остаток по классам до и после исправления, покрытие, абзацы исключённых регионов в
  выходе, цена. Прослушивание трёх глав в ElevenLabs — шаг владельца (голос и модель — его выбор), результат
  записывается в Changelog.

## Success Criteria *(mandatory)*

- **SC-001**: на трёх замерах FR-008 в выходе 0 абзацев регионов `front_matter` (кроме заголовка книги), оглавления,
  указателя, справочного аппарата, таблиц и подписей; 0 HTML, эмодзи, тегов в скобках.
- **SC-002**: после исправления абзацев с цифрами ≤ 1 % от озвучиваемых (каждый оставшийся прочитан и объяснён);
  до исправления — опубликовано как есть.
- **SC-003**: покрытие — 0 потерянных абзацев основного текста, 0 склеек.
- **SC-004**: перевод и редактура — запросы и промпты побайтно как до спеки (кроме исчезнувшего второго прохода);
  `.tts.txt` они не пишут; полный прогон тестов зелёный.
- **SC-005**: цена аудиокниги на полной книге — опубликована (оценки цены в UI для этого режима спека не строит).
- **SC-006**: приёмочное ревью Codex по всем затронутым поверхностям до слияния в `main`.

## Non-goals

- **Нарезка на главы для ElevenLabs Studio** (ZIP или EPUB с `<h1>`, `REVIEW.md` №16) — не в этой спеке: сначала
  чистый текст, потом формат импорта; один файл остаётся.
- **Синтез речи через API ElevenLabs и автоматическое прослушивание** — не строится; слушает владелец.
- **Теги интонации как опция** — нет (D-3).
- **Словарь «ё», транслитерация латиницы, словарь чисел** — нет (Конституция VII): числа словами и «ё» — задача
  модели по правилу формы; код только находит остаток.
- **Перевод внутри режима аудиокниги** — нет (D-1): на английском входе выход английский.
- **Оценка цены аудиокниги в UI** — не строится в этой спеке (только замер факта).

## Anti-regression

1. Перевод и редактура: те же запросы, промпты, бюджеты; единственное изменение — нет второго прохода и `.tts.txt`.
2. Озвучка не блокирует доставку: обзор и остаток — данные проверки, как сейчас (spec 054).
3. Исключение — по региону и роли, никогда по словам; счётчики исключений с адресами абзацев сохраняются.
4. Конституция VII: классы символов — по категориям Unicode; ни словарей слов, ни литералов книг ни в коде, ни в
   тестах.
5. Канонические пути (AGENTS.md): тесты — `scripts/test.sh` через WSL; прогоны — `scripts/run-real-document-validation.sh`;
   полный прогон в главном дереве и пустой `git status --porcelain` перед «зелёным».
6. Тесты промпта проверяют поведение (сборка промпта без противоречий, ответ с остатком ведёт к исправлению), а не
   наличие фраз.

## Assumptions

- Модель режима — `[models.text].default` (сейчас flash-lite) или `[models.audiobook]`, если задана; перевод чисел в
  слова с падежами на русском этой моделью — проверяет FR-008.
- Регион `front_matter`, роли оглавления, таблицы и подписи вычисляются подготовкой и на переведённом DOCX (вход
  режима — выход нашего же конвейера).
