## Решения владельца (2026-11-10)

- **D-1. Транслитерация латиницы возвращается — для аудиокниги.** Спека 070 записала в Non-goals «транслитерация
  латиницы — нет» (`specs/070-audiobook-technical-pass/spec.md:264-266`); это было решение спеки (против словаря
  транслитерации), не владельца. Проба: MiniMax читает латиницу «неплохо, но с акцентом», транслитерацию —
  «идеально»; ElevenLabs читает латиницу так же, как транслитерацию.
- **D-2. Версия текста для MiniMax** — нужна; разбивку на главы, генерацию, скачивание и хранение аудио делает
  приложение владельца (Voice Studio), не этот проект. **Заменено решением D-4.**
- **D-4 (2026-11-10). Файл книги вместо `.tts.minimax.txt`.** Для отдельного инструмента поэтапной озвучки владельца
  (`D:\Temp\docxai-research\audiobook-studio\ARCHITECTURE.md`) режим аудиокниги выдаёт `<stem>.narration.json`: главы,
  сегменты с происхождением, виды пауз и словарь чтения — данными; тишину инструмент вставляет сам при сборке. Причина:
  книгу в 459 000 знаков нельзя вставить в инструмент клипов на 10 000 знаков, а паузы данными настраиваются без
  перегенерации. Полную книгу АУДИО ради проверки не генерировать никогда; замер FR-012 — только подготовка текста
  моделью.
- **D-3. Крайние случаи не шлифуются** (решение владельца 2026-11-10 по спеке 070).

## User Scenarios & Testing *(mandatory)*

### User Story 1 — Голос не спотыкается (Priority: P1)

Владелец готовит аудиокнигу и слушает её в ElevenLabs или в своём Voice Studio на MiniMax: омографы с ударением на
месте, иностранные имена и названия звучат по-русски без акцента, сокращения и номера разделов читаются во всей книге
одинаково.

**Acceptance Scenarios**:
1. **Given** «на двери висел новый замок», **Then** в тексте «замо́к»; **Given** «старый замок на холме», **Then**
   «за́мок»; слово без неоднозначности знака не получает.
2. **Given** «Компании Interface и Herman Miller», **Then** «Компании Интерфейс и Герман Миллер».
3. **Given** TRC встречается в книге двадцать раз, **Then** все двадцать раз — одно и то же чтение.
4. **Given** заголовки «1. …», «2. …», «3. …», **Then** номер в них читается одной формой во всех заголовках книги.

### User Story 2 — Файл книги для инструмента озвучки (Priority: P2)

Владелец скачивает «Файл книги для озвучки (.json)» и импортирует его в свой отдельный инструмент поэтапной озвучки
(D-4): главы, абзацы-сегменты с происхождением, виды пауз и словарь чтения книги приходят данными; тишину инструмент
вставляет сам при сборке аудио, поэтому меток пауз в тексте нет.

**Acceptance Scenarios**:
1. **Given** глава с подзаголовками и разделителем `***`, **Then** в `.narration.json` у сегмента названия главы
   `pause_after.kind = "chapter"`, у подзаголовка — `"heading"`, у сегмента перед разделителем — `"scene_break"`;
   у сегмента не больше одного вида паузы.
2. **Given** тексты сегментов `.narration.json` соединены через `"\n\n"`, **Then** результат побайтно равен `.tts.txt`.

### Edge Cases

- Знак ударения в слове, которое модель сочла неоднозначным без причины, — допустим (Д-3); проверка — доля слов со
  знаком в выборке FR-010.
- Латинская аббревиатура (TRC) — чтение из словаря чтения книги (FR-004), не побуквенная транслитерация.
- Латиница внутри адреса сайта — класс `url_or_domain`, как сейчас.
- Перевод и редактура — ничего не меняется.

## Requirements *(mandatory)*

- **FR-001 — Ударения в омографах.** Промпты режима аудиокниги (основной и исправления) требуют ставить знак ударения
  U+0301 над ударной гласной в слове, которое пишется одинаково с другим словом и читается иначе, когда ударение ясно
  из контекста; в остальных словах знака нет; другие способы (заглавная, «+», апостроф, транскрипция) запрещены.
  Словаря омографов нет (Конституция VII) — решение модели по правилу. Лишний знак — принятый крайний случай (D-3).
- **FR-002 — Знак ударения не ломает лексические сравнения.** Один общий помощник «текст без комбинирующих знаков»
  (категория Unicode M*; сегодня `_without_combining_marks`, `document/narration_exclusion.py:93-96`, переносится в
  общий модуль и вызывается оттуда) применяется во всех ЛЕКСИЧЕСКИХ сравнениях: покрытие абзаца, детектор остатка
  (`all_caps`, `roman_numerals`, новый `latin`), правило обрывка (уже), проверка протечки контекста
  (`generation/_generation.py:78`). Где сравнение отдаёт адрес совпадения, позиции сохраняются относительно исходной
  строки. Проверка ТОЧНОЙ сборки по ID и текстам (`pipeline/narration_postprocess.py:138-185`) остаётся побайтной —
  потерю самого знака она должна видеть. Детерминированная склейка body+body знаком не затрагивается.
- **FR-003 — Транслитерация латиницы.** Промпты (основной и исправления) требуют передавать слова латиницей
  кириллицей так, как их произносят по-русски (имена, названия, термины). Приоритет правил записан в промпте:
  латинская аббревиатура — по словарю чтения (FR-004), а если её там нет — названиями букв по-русски; латинский
  инициал — названием буквы по-русски (правило инициалов спеки 070 — не выдумывать полное имя — сохраняется);
  правило «аббревиатуры оставляйте как есть» относится только к кириллическим аббревиатурам, которых нет в словаре.
  Детектор остатка получает класс `latin`: единица — максимальная серия букв, дефисов и апострофов, содержащая хотя бы
  одну букву, в имени символа Unicode которой есть `LATIN` (без списка букв); не считаются: серия внутри найденного
  адреса сайта (класс `url_or_domain` маскирует её), серия, целиком распознанная как римское число. Класс исправимый:
  остаток уходит в тот же единственный вызов исправления на блок (спека 070) — блок с несколькими классами остатка
  даёт ровно один оплачиваемый вызов (тест): повторов SDK нет; повторная отправка после ОТКЛОНЁННОГО запроса, не
  давшего ответа (переход Responses → Chat Completions при несовместимости, `generation/_generation.py:2305-2314`;
  повтор без отклонённого необязательного параметра, `image/shared.py:265-272`), допустима и повтором не считается. Химические формулы и единицы латиницей (`H₂O`, `kg`) — принятая граница: они
  уходят в исправление как латиница.
- **FR-004 — Словарь чтения сокращений.** Обязательный шаг прогона аудиокниги перед первым блоком (решение владельца
  2026-11-10: словарь — часть функционала, его сбой не обычный исход). Один логический шаг на книгу из пакетов: кандидаты
  идут пакетами по `READING_GLOSSARY_BATCH_SIZE = 40` (ответ пакета с запасом в бюджете вывода; на полной Money 67
  кандидатов — 2 пакета, при пределе 200 — 5); каждый пакет вызывается с той же политикой повторов, что вызов модели
  блока (`context.max_retries` попыток, повтор на повторяемой ошибке и на неразборчивом ответе, пауза
  `min(2 ** (попытка − 1), 8)` с — `generation/_generation.py:3541-3606`); пакет повторяется сам, не отравляя
  остальные. После первого прохода кандидаты без принятого чтения (не отвечены или отклонены проверкой формы)
  запрашиваются ОДИН раз повторно, отдельными пакетами. Только если модель недоступна после всех повторов какого-либо
  пакета, шаг ПАДАЕТ — так же, как падает неисправимый вызов модели блока аудиокниги сегодня
  (`pipeline/block_failures.py:135-243`: ошибка в состоянии, итог прогона «ошибка», без выдачи); ветки «книга без
  словаря» нет. Стадия стоимости `audiobook_reading_glossary`; Stop перед шагом и между пакетами — прогон
  останавливается, как на соседних границах. Механизм глоссария перевода переиспользуется по частям (рендер секции,
  форма запроса, бюджет ответа, разбор JSON, артефакт прогона), фаза перевода не вызывается и не меняется.
  **Кандидаты** — по форме, только сокращения: единица по тому же правилу серии, что FR-003 (дефис и цифры внутри
  допускаются: `TRC`, `CoR-EU`, `EA-16` — одна единица), в которой не меньше двух заглавных букв и заглавных больше,
  чем строчных (любая письменность), из озвучиваемых абзацев исходника; не кандидаты — единица, целиком римское число
  (форма класса `roman_numerals`), единица внутри адреса сайта, любая единица абзаца, целиком набранного заглавными
  (форма класса `all_caps`). Не больше `N = 200` различных (замер плана: 67 на полной Money, 17 и 4 на главах — research
  R4); при превышении — самые частые, число отброшенных в событии, их написания в артефакте. Имена с заглавной буквы — не
  кандидаты (Non-goals). **Ответ** — для каждого кандидата одно чтение кириллицей (со знаком ударения, где нужен). Пустой список
  кандидатов — вызова нет. Каждое чтение проверяется по форме (кириллица, без цифр и латиницы, написание кандидата
  совпало). Кандидат, оставшийся без принятого чтения и после повторного запроса, — НЕ обычный исход: `WARNING` с
  числом и написаниями в артефакте (review data); для него действует правило промпта FR-003, прогон продолжается
  (модель доступна — это крайний случай качества ответа, D-3). Полный ответ — `INFO`. **Доставка**: секция «Как читать сокращения этой книги» добавляется к уже полученному
  системному промпту — основному и исправления — для каждого блока отдельно: только записи, чей кандидат встречается
  в ИСХОДНИКЕ этого блока (точное совпадение единицы, как при отборе); записи предыдущего блока не переносятся.
  Правило промпта: сокращение из секции читать ровно так, склоняя по контексту, если это слово.
- **FR-005 — Номера разделов в заголовках.** Правило промпта: число или римское число в начале заголовка с точкой
  («1.», «IV.») читается порядковым числительным среднего рода с точкой — «Первое.», «Четвёртое.» — и ничего не
  добавляется (слов «глава», «раздел» нет, если их нет в исходнике). Номер виден и сквозь разметку выделения в начале
  заголовка (`**1. …**` — 10 из 46 таких заголовков полной Money). Правило одно на все заголовки; словаря чисел нет.
  Если перед номером стоит слово, заголовок начинается не с номера: слово остаётся, номер пишется словами в согласии с
  ним; ни в один заголовок не добавляются номер или слово, которых в нём нет, и заголовок не повторяется (замер WP-Y,
  Changelog 2026-11-10).
- **FR-006 — Сигнал разделителя сцены.** Абзац, исключённый с причиной `fragment`, чей исходный текст непуст и не
  содержит ни буквы, ни цифры (та же форма, что правило `document/narration_exclusion.py:161-167` для ролей вне правила
  обрывка; абзац тела `***` исключает общее правило обрывка `:168-169` с той же причиной), и стоящий между двумя
  озвучиваемыми абзацами, оставляет в сборке отметку границы: следующая группа абзацев несёт признак «после
  разделителя». Исключения по другим причинам между ними отметку не ставят и не гасят. Отметка запрещает
  детерминированную склейку body+body через разделитель. Несколько разделителей подряд — одна отметка; разделитель в
  начале или в конце книги — без отметки. Пустые абзацы и исключения по другим причинам отметки не дают. `.tts.txt`
  меняется только там, где раньше была склейка через разделитель (такие места публикуются в замере FR-012).
- **FR-007 — Файл книги для озвучки `<stem>.narration.json` (`schema_version: 1`, решение D-4).** Заменяет
  `.tts.minimax.txt`; меток `<#x#>` в тексте нет. Схема — по контракту импорта инструмента (`ARCHITECTURE.md` §6.4),
  сужена до того, что DocxAICorrector знает (полностью — `contracts/narration-book.md`):
  - **сегменты** — ровно группы `.tts.txt` (спека 072, с признаком FR-006) в том же порядке:
    `"\n\n".join(segment.text) == .tts.txt` побайтно (тест контракта); у сегмента `ordinal` (с 1), `chapter_ordinal`,
    `role` (роль группы), `heading_level` (уровень группы или `null`), `text`, `after_scene_break` (FR-006),
    `pause_after` (`{"kind", "seconds"}` или `null`), `source_paragraph_ids` (ID `pNNNN` — только происхождение);
  - **главы** — по правилу глав спеки 072 (`NarrationDocumentPlan`): каждый абзац плана `Heading 1` открывает главу;
    абзацы до первого `Heading 1` — отдельная глава без названия (`title: null`), как считает
    `StudioLimits.chapter_count_for_limits` (`pipeline/narration_document.py:86-97`, `:130-160`); книга без `Heading 1` —
    одна глава; у главы `ordinal`, `title` (текст абзаца плана `Heading 1`, то есть слитой серии) и `segment_ordinals`;
  - **вид паузы** — по прежнему правилу этого FR: последний сегмент серии-главы (серия и ранг — из плана 072) —
    `chapter`; последний сегмент серии остальных заголовков — `heading`; сегмент перед сегментом с
    `after_scene_break` — `scene_break`; совпадение — бо́льшая пауза; у последнего сегмента книги паузы нет; между
    абзацами тела — `null` (паузу абзаца задаёт инструмент). Секунды — значения по умолчанию из замера MiniMax
    (1,5 / 0,8 / 2,0 с), записанные в файл; инструмент вправе менять их без перегенерации;
  - **словарь чтения** — принятые записи FR-004 (`abbreviation`, `reading`);
  - **`producer`** — `name`, `version` (git SHA кода или `null`, если недоступен), `run_id`, `produced_at` (UTC);
    **`book`** — только `source_name` и `source_token`: названия и автора DocxAICorrector не знает и не выдумывает,
    языка у режима аудиокниги нет; **`stats`** — числа прогона;
  - **версия:** набор полей верхнего уровня закрыт; `schema_version` растёт только при несовместимом изменении;
    неизвестное поле верхнего уровня — ошибка импорта на стороне инструмента. Устойчивые ID сегментов — задача
    инструмента (Non-goals).

  Сбой сборки файла — `WARNING`, книга выдаётся без него (Anti-regression 2).
- **FR-008 — Артефакт, экран, раннер.** `.narration.json` — член группы результата (состав по собранному, атомарная
  публикация, суффикс `.result.narration.json` в хранении; имя при скачивании и в раннере — `<основа>.narration.json`),
  ключ `narration_book_path` в `ui_audiobook_artifact_saved`, кнопка «Файл книги для озвучки (.json)» в строке «Текст
  для озвучки» (спека 072), доставка через разрешённые ключи состояния и bundle — в составе `latest_narration_exports`
  (спека 072, контракт состояния). Раннер реальных документов сохраняет `.narration.json` и артефакт словаря чтения в
  каталог прогона, перечисляет в `output_artifacts` и сводке, берёт счётчики FR-010 из события. Старый bundle, новый
  запуск, Stop — как в спеке 072.
- **FR-009 — Совместимость.** `.tts.txt` и `.tts.docx` несут ударения и транслитерацию тем же текстом; PDF — визуально
  (текстовый слой PDF знак ударения не гарантирует — Non-goal спеки 072). Слияния и стили спеки 072 сохраняются.
- **FR-010 — Учёт.** Событие аудиокниги пишет: знаков ударения (всего и на 1 000 слов); единиц `latin` в исходнике
  озвучиваемых абзацев (знаменатель SC-001), до и после исправления; кандидатов словаря — найдено, отправлено, принято,
  запрошено повторно, без чтения после повтора, отброшено по пределу; пакетов, вызовов и повторов шага словаря; блоков,
  получивших записи;
  отметок разделителя; пауз по видам в файле книги; стоимость стадии словаря.
- **FR-011 — Перевод и редактура** — без изменений (золотые тесты спеки 070).
- **FR-012 — Замер.** База — три существующих канонических прогона на коде, который производит сегодняшний `.tts.txt`
  (RM гл. 3 `20261110T080357Z`, Money гл. 3 `20261110T080639Z`, полная Money `20261110T145422Z` — после слияния 072;
  проверено по истории кода, research R14; если до замера в текст озвучки войдёт чужой коммит — сначала новая база,
  ≈ 0,39 $). Канонические прогоны тех же трёх входов с этой спекой — ≈ 0,42 $ (прогноз research R13: шаг словаря —
  2 пакета на полной Money и по 1 на главах, секции в блоках, правила промпта, дополнительные исправления), с согласия
  владельца. Публикуется: латиница до/после, ударения на 1 000 слов, для каждого кандидата словаря — все
  вхождения в выходе и их формы, номера разделов во всех заголовках, места бывших склеек через разделитель,
  стоимость по стадиям; чтение 30 пар на главу; владелец слушает главу в ElevenLabs и в Voice Studio.

## Success Criteria *(mandatory)*

- **SC-001**: единиц `latin` вне адресов сайтов в итоговом тексте — 0 на трёх входах FR-012 (после одного
  исправления); знаменатель — единиц `latin` в исходнике озвучиваемых абзацев — опубликован и не равен нулю (замер плана:
  5 / 44 / 528); единиц до исправления — опубликовано (может быть 0: на RM база уже 0).
- **SC-002**: для каждого принятого кандидата словаря все его вхождения в выходе — одно чтение. Замер — по каждой
  принятой записи: исходные вхождения с ID абзацев, сопоставленный абзац выхода, число подтверждённых / отсутствующих
  / неоднозначных. **Одно чтение — по форме:** вхождение подтверждено, если в сопоставленном абзаце выхода есть
  последовательность слов, каждое из которых (без знаков ударения и регистра) равно слову принятого чтения или
  совпадает с ним без двух последних букв (основа не короче трёх букв — падежное окончание может меняться); в абзаце
  подтверждено `min(вхождений в исходнике, найденных чтений)`, остальные — отсутствующие; найденных больше, чем
  вхождений, — абзац неоднозначный (публикуется, не провал). Запись проходит при ≥ 1 проверенном вхождении и 0
  отсутствующих. Знаменатели (найдено / отправлено / принято / вхождений проверено) опубликованы, отброшенные пределом —
  названы. Пустой словарь или 0 проверенных вхождений — «не проверено», никогда не «пройдено». На полной Money TRC и
  CoR-EU — каждое одним чтением.
- **SC-003**: номера в начале заголовков главы III Money и полной Money — одной формой по FR-005 (все заголовки с
  номером перечислены).
- **SC-004**: ударения — в выборке FR-012 опубликованы число омографов с ясным контекстом (непустой набор,
  отобранный по списку из чтения, не кодом), сколько из них со знаком, и число знаков в словах без
  неоднозначности на 1 000 слов; порог не ставится (D-3), решение — по слуху владельца.
- **SC-005**: пара синтетических абзацев (не меньше четырёх длинных слов и шести токенов) с ударениями и без даёт
  одинаковое покрытие, одинаковый остаток и одинаковую проверку протечки; контрпример с настоящей потерей
  предложения по-прежнему ловится.
- **SC-006**: в `.narration.json` `"\n\n".join(segment.text)` побайтно равен `.tts.txt` (на синтетике и на собранном
  тексте позднего этапа; с U+0301 и `\n` внутри сегмента); виды пауз по FR-007 на синтетическом наборе (глава из серии
  `2 → 1`, подзаголовок, разделитель между body, два разделителя подряд, разделитель у заголовка, разделитель в начале и
  конце, конец книги); у сегмента не больше одного вида; главы — по правилу 072 (глава без названия до первого
  `Heading 1`; книга без `Heading 1` — одна глава); каждый сегмент — ровно в одной главе; набор полей верхнего уровня —
  закрытый (`contracts/narration-book.md`).
- **SC-007**: блок с остатком нескольких классов, включая `latin`, — ровно один оплачиваемый вызов исправления
  (подменённый клиент: успешная первая отправка — ровно один запрос; обычное исключение транспорта не повторяется;
  повторная отправка допустима только после отклонённого запроса без ответа — FR-003). Словарь (подменённый клиент):
  пакетов первого прохода — `ceil(отправлено / 40)`, успешный пакет — ровно один вызов; сбойный пакет повторяется сам по
  политике блока, остальные пакеты не повторяются; кандидаты без чтения запрашиваются повторно ровно один раз; модель,
  недоступная после всех повторов, — итог прогона «ошибка» тем же путём, что неисправимый вызов блока. Секция словаря
  блока содержит только его записи (сравнение реальных аргументов двух блоков и исправления).
- **SC-010**: словарь без сбоя на корпусе — на трёх входах FR-012 каждый отправленный кандидат получил принятое чтение
  (без чтения после повтора — 0; найдено / отправлено / принято опубликованы: прогноз 4 / 17 / 67), шаг не упал.
- **SC-008**: перевод и редактура — те же запросы (золотые тесты).
- **SC-009**: приёмочное ревью Codex по всем затронутым поверхностям до слияния в `main`.

## Non-goals

- **Книга на языке с латинской письменностью в режиме аудиокниги** — нет (решение оркестратора 2026-11-10, при
  слиянии WP-C): на вход режима идёт уже переведённый на русский документ, промпт написан по-русски и несёт
  русские правила (`ё`, транслитерация «как произносят по-русски»); класс `latin` на такой книге отметил бы почти
  каждый абзац. Тестовые примеры аудиокниги с английским текстом заменены русскими (`tests/test_document_pipeline.py`,
  `tests/test_narration_markdown.py`, `tests/test_narration_residue.py`).
- **Имена в словаре чтения** — нет: латинские уходят в транслитерацию (FR-003), кириллические модель читает сама;
  широкий отбор «слова с заглавной» даёт сотни записей (842 на полной Money).
- **Звуки-теги** (`(laughs)`, `(sighs)`, `(breath)`), эмоции по абзацам, голоса персонажей — для научно-популярных
  книг не нужны.
- **Файл словаря произношения сервиса** (`.pls`, `pronunciation_dict`) — чтение пишется прямо в текст.
- **Ударения во всех словах** — только омографы; **проверка правильности ударения кодом** — нет (D-3).
- **Знак ударения в текстовом слое PDF** — не гарантируется (Non-goal спеки 072).
- **Химические формулы и единицы** как отдельный случай — нет (FR-003, граница).
- **Разбивка на главы, генерация и хранение аудио** — отдельный инструмент владельца (D-4).
- **Метки пауз `<#x#>` в тексте и файл `.tts.minimax.txt`** — нет (решение D-4): паузы — данные файла книги, тишину
  вставляет инструмент при сборке.
- **Устойчивые ID сегментов между прогонами** — нет: `source_paragraph_ids` (`pNNNN`) — только происхождение,
  контент-адресные ID и выравнивание при повторном импорте — задача инструмента (`ARCHITECTURE.md` §6.3).
- **Название, автор и язык книги в файле книги** — нет: DocxAICorrector их не знает и не выдумывает; инструмент
  спрашивает их сам.
- **Генерация АУДИО полной книги ради проверки** — никогда (владелец 2026-11-10); замер FR-012 — только подготовка
  текста моделью.
- **Изменение глоссария перевода** — его части переиспользуются, поведение перевода не меняется.
- **Отсев несокращений среди кандидатов словаря** — нет: отбор по форме пропускает слова заглавными, которые не
  сокращения (по ручной классификации Codex — 17 из 67 кандидатов полной Money, 26 вхождений; на RM `ЧЕМ` и `СУТЬ` из
  заголовка «В ЧЕМ СУТЬ?» — его не исключает форма `all_caps`, которой нужны два слова от четырёх букв). Это принятая
  граница: чтение такого слова — оно же обычным регистром; списка слов-исключений нет (Конституция VII).
- **Новая политика транспорта** (ограничение повторной отправки после отклонённого запроса) — нет: у исправления
  оплачивается один вызов (FR-003); словарь берёт политику повторов вызова блока (FR-004), своей не заводит.
- **Уведомление на экране о сбое словаря** — нет (решение владельца 2026-11-10): сбой словаря не обычный исход; модель
  недоступна — прогон падает, как на блоке; кандидат без чтения — review data в событии и артефакте.
- **Хвост повтора/soak в раннере** — принято как граничный случай: путь повторных прогонов
  (`tests/artifacts/real_document_pipeline/run_lietaer_validation.py:3794`) не переносит файл книги и словарь в
  родительский `latest`; у профиля аудиокниги `repeat_count=1` (приёмочное ревью Codex 2026-11-10, P3).

## Anti-regression

1. Перевод и редактура: те же запросы, промпты и файлы (золотые тесты спеки 070).
2. Озвучка не блокирует выдачу: исправление латиницы и `.narration.json` при сбое — `WARNING`, книга выдаётся. Словарь —
   обязательный шаг: недоступная модель роняет прогон ТЕМ ЖЕ путём, что неисправимый вызов блока
   (`pipeline/block_failures.py:135-243`), без новой ветки деградации; кандидат без чтения — `WARNING`, прогон идёт.
3. Конституция VII: ни словаря омографов, ни словаря транслитерации, ни списка сокращений, ни словаря чисел;
   кандидаты — по форме; классы символов — по свойствам Unicode; в тестах — синтетические тексты той же формы.
4. Строго один оплачиваемый вызов исправления на блок; обычное исключение транспорта не повторяется. Словарь — один
   логический шаг на книгу: пакеты первого прохода, повторы пакета только по политике вызова блока, один повторный
   запрос кандидатов без чтения; не больше.
5. Знак ударения сохраняется побайтно в `.tts.txt`, `.tts.docx` и текстах сегментов `.narration.json` (JSON без
   экранирования не-ASCII); проверка точной сборки остаётся чувствительной к его потере.
6. Словарь одного прогона не попадает в другой (артефакт и секция — в пределах прогона).
7. Структурные сигналы 072 (группы, серии, ранг главы) не меняются; новый сигнал разделителя только добавляется.
8. Канонические пути (AGENTS.md): тесты — `scripts/test.sh` через WSL; прогоны — `scripts/run-real-document-validation.sh`;
   полный прогон в главном дереве и пустой `git status --porcelain` перед «зелёным»; финальное доказательство — задача
   VS Code `Run Full Pytest`, а где путь задачи недоступен, это сказано прямо и доказательством служит shell-прогон
   оркестратора.
9. Замер SC-002 не вакуумен: пустой словарь или 0 проверенных вхождений — «не проверено»; каждое исходное вхождение
   учтено как подтверждённое, отсутствующее или в неоднозначном абзаце.
10. Файл книги — проекция тех же групп, что `.tts.txt`: никакого второго текста; тест контракта
    `"\n\n".join(segment.text) == .tts.txt` на собранном тексте позднего этапа; поля верхнего уровня — закрытый набор
    `schema_version: 1`.

## Assumptions

- Модель режима (flash-lite) ставит ударения в омографах по правилу промпта с полезной точностью — проверяется
  чтением и слухом FR-012; если нет — модель режима выбирает владелец.
- Сокращений на книгу — десятки: замер плана без модели — 67 различных на полной Money, 17 на главе Money, 4 на главе
  RM (research R4); предел `N = 200`.
- Инструмент озвучки владельца импортирует `.narration.json` по `contracts/narration-book.md`; пример §6.4
  `ARCHITECTURE.md` шире (название, автор, язык) — инструмент не требует этих полей и спрашивает их у владельца
  (прогноз по архитектуре; инструмент ещё не построен).
