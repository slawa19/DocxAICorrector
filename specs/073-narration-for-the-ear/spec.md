## Решения владельца (2026-11-10)

- **D-1. Транслитерация латиницы возвращается — для аудиокниги.** Спека 070 записала в Non-goals «транслитерация
  латиницы — нет» (`specs/070-audiobook-technical-pass/spec.md:264-266`); это было решение спеки (против словаря
  транслитерации), не владельца. Проба: MiniMax читает латиницу «неплохо, но с акцентом», транслитерацию —
  «идеально»; ElevenLabs читает латиницу так же, как транслитерацию.
- **D-2. Версия текста для MiniMax** — нужна; разбивку на главы, генерацию, скачивание и хранение аудио делает
  приложение владельца (Voice Studio), не этот проект.
- **D-3. Крайние случаи не шлифуются** (решение владельца 2026-11-10 по спеке 070).

## User Scenarios & Testing *(mandatory)*

### User Story 1 — Голос не спотыкается (Priority: P1)

Владелец готовит аудиокнигу и слушает её в ElevenLabs или в своём Voice Studio на MiniMax: омографы с ударением на
месте, иностранные имена и названия звучат по-русски без акцента, сокращения и номера разделов читаются во всей книге
одинаково.

**Acceptance Scenarios**:
1. **Given** «на двери висел новый замок», **Then** в тексте «замо́к»; **Given** «старый замок на холме», **Then**
   «за́мок»; слово без неоднозначности знака не получает.
2. **Given** «Компании Interface и Herman Miller», **Then** «Компании Интерфейс и Герман Миллер».
3. **Given** TRC встречается в книге двадцать раз, **Then** все двадцать раз — одно и то же чтение.
4. **Given** заголовки «1. …», «2. …», «3. …», **Then** номер в них читается одной формой во всех заголовках книги.

### User Story 2 — Версия для MiniMax (Priority: P2)

Владелец скачивает «Текст для озвучки — MiniMax»: тот же текст, что `.tts.txt`, но с паузами `<#x#>` после названия
главы, после подзаголовка и на месте разделителя сцен; вставляет главы в Voice Studio без ручной расстановки пауз.

**Acceptance Scenarios**:
1. **Given** глава с подзаголовками и разделителем `***`, **Then** в `.minimax.txt` после названия главы `<#1.5#>`,
   после подзаголовка `<#0.8#>`, на месте разделителя `<#2.0#>`; две метки подряд не стоят никогда.
2. **Given** метки убраны, **Then** текст `.minimax.txt` равен `.tts.txt`.

### Edge Cases

- Знак ударения в слове, которое модель сочла неоднозначным без причины, — допустим (Д-3); проверка — доля слов со
  знаком в выборке FR-010.
- Латинская аббревиатура (TRC) — чтение из словаря чтения книги (FR-004), не побуквенная транслитерация.
- Латиница внутри адреса сайта — класс `url_or_domain`, как сейчас.
- Перевод и редактура — ничего не меняется.

## Requirements *(mandatory)*

- **FR-001 — Ударения в омографах.** Промпт режима аудиокниги (основной и исправления) требует ставить знак ударения
  U+0301 над ударной гласной в слове, которое пишется одинаково с другим словом и читается иначе, когда ударение ясно
  из контекста; в остальных словах знака нет; другие способы (заглавная, «+», апостроф, транскрипция) запрещены.
  Словаря омографов нет (Конституция VII) — решение модели по правилу.
- **FR-002 — Знак ударения не ломает проверки.** Покрытие, детектор остатка, правило обрывка, детерминированная
  склейка и границы абзацев считают слова без комбинирующих знаков (категория Unicode M*) — одним общим помощником,
  уже существующим (`_without_combining_marks`), вынесенным в общий модуль; знак в выводе сохраняется побайтно
  (`.tts.txt`, `.tts.docx`, `.minimax.txt`).
- **FR-003 — Транслитерация.** Промпт требует передавать слова латиницей кириллицей так, как их произносят по-русски
  (имена, названия, термины); латинская аббревиатура — по словарю чтения книги (FR-004) или буквами по-русски.
  Детектор остатка получает класс `latin` — буква латиницы (по имени символа Unicode, не по списку) вне адреса сайта;
  класс исправимый: остаток уходит в тот же единственный вызов исправления на блок (спека 070 FR-006).
- **FR-004 — Словарь чтения книги.** Один вызов модели на книгу перед первым блоком аудиокниги (как глоссарий
  перевода, на его механизме: кандидаты по форме, бюджет, секция системного промпта, артефакт, учёт стоимости
  стадией `audiobook_reading_glossary`). Кандидаты по форме: слова заглавными (аббревиатуры), слова латиницей,
  слова с заглавной в середине предложения (имена), номера в начале заголовков. Модель отдаёт для каждого кандидата
  чтение (кириллицей, со знаком ударения, где нужен) и единую форму номера раздела для заголовков. Каждый блок
  получает в системном промпте записи словаря, встречающиеся в этом блоке; правило промпта — читать их ровно так.
  Отказ или неразборчивый ответ — блоки идут без словаря, `WARNING`, книга выдаётся.
- **FR-005 — Версия для MiniMax.** Из тех же групп абзацев (спека 072 FR-001) — файл `.minimax.txt`: абзацы через
  перевод строки; после группы-главы (заголовок ранга главы, спека 072 FR-003) — `<#1.5#>`; после остального
  заголовка — `<#0.8#>`; на месте исключённого абзаца без букв и цифр между озвучиваемыми (разделитель сцены) —
  `<#2.0#>`; метка только между произносимыми фрагментами, двух подряд нет (правило MiniMax). Значения — константы
  с ссылкой на замер. Других меток (звуки, эмоции) нет.
- **FR-006 — Артефакт и экран.** `.minimax.txt` — член группы результата (атомарная публикация, суффикс в
  хранении), ключ `tts_minimax_path` в `ui_audiobook_artifact_saved`, кнопка «MiniMax» в строке «Текст для озвучки»
  (спека 072 FR-009), доставка через разрешённые ключи состояния и bundle (спека 072 FR-008).
- **FR-007 — Совместимость.** `.tts.txt`, `.tts.docx`, `.tts.pdf` получают ударения и транслитерацию тем же текстом;
  других различий нет.
- **FR-008 — Учёт.** Событие аудиокниги пишет: число знаков ударения, число слов латиницей до и после исправления,
  размер словаря чтения и число блоков, получивших его записи, стоимость стадии словаря.
- **FR-009 — Перевод и редактура** — без изменений (золотые тесты спеки 070).
- **FR-010 — Замер.** Канонический прогон глав RM и Money (≈ 0,06 $) и полной Money (≈ 0,40 $) — с согласия
  владельца: латиница после исправления, ударения на 1 000 слов, одинаковость чтения сокращений и номеров разделов по
  книге (каждое вхождение каждого кандидата словаря), стоимость; чтение 30 пар на главу; владелец слушает главу в
  ElevenLabs и в Voice Studio.

## Success Criteria *(mandatory)*

- **SC-001**: латиница вне адресов сайтов в итоговом тексте — 0 слов на трёх входах FR-010 (после одного исправления).
- **SC-002**: каждое сокращение и номер раздела из словаря чтения читается во всех вхождениях одной формой; на
  полной Money TRC и CoR-EU — по одной форме, номера разделов главы III — одной формой.
- **SC-003**: в выборке 30 пар на главу ударение поставлено во всех встреченных омографах с ясным контекстом и не
  больше чем в 1 слове из 200 без неоднозначности (прогноз; цифра публикуется).
- **SC-004**: покрытие и остаток не дают ложных пометок из-за знака ударения (тест на синтетическом абзаце; на
  прогоне — `low_coverage` не растёт против FR-009 спеки 070).
- **SC-005**: `.minimax.txt` без меток равен `.tts.txt`; метки стоят по FR-005, двух подряд нет (тест).
- **SC-006**: перевод и редактура — те же запросы (золотые тесты).
- **SC-007**: приёмочное ревью Codex по всем затронутым поверхностям до слияния в `main`.

## Non-goals

- **Звуки-теги** (`(laughs)`, `(sighs)`, `(breath)`), эмоции по абзацам, голоса персонажей — для научно-популярных
  книг не нужны; отдельная работа, если появятся художественные.
- **Файл словаря произношения сервиса** (`.pls` для ElevenLabs, `pronunciation_dict` для MiniMax) — чтение пишется
  прямо в текст (проба: словарь MiniMax не гарантирует каждое вхождение); выгрузку можно добавить позже.
- **Ударения во всех словах** — только омографы.
- **Проверка правильности ударения и чтения** кодом — нет (D-3; слушает владелец).
- **Разбивка на главы, генерация и хранение аудио** — Voice Studio владельца.
- **Изменение переводческого глоссария** — его механизм переиспользуется, поведение перевода не меняется.

## Anti-regression

1. Перевод и редактура: те же запросы, промпты и файлы (золотые тесты спеки 070).
2. Озвучка не блокирует выдачу: словарь чтения, исправление латиницы и `.minimax.txt` при сбое — `WARNING`, книга
   выдаётся (спека 070 Anti-regression 2).
3. Конституция VII: ни словаря омографов, ни словаря транслитерации, ни списка сокращений; кандидаты — по форме;
   классы символов — по свойствам Unicode; в тестах — синтетические тексты той же формы.
4. Строго один вызов исправления на блок (спека 070); латиница добавляется в тот же вызов, не вторым.
5. Знак ударения сохраняется побайтно во всех выходах.
6. Канонические пути (AGENTS.md): тесты — `scripts/test.sh` через WSL; прогоны — `scripts/run-real-document-validation.sh`;
   полный прогон в главном дереве и пустой `git status --porcelain` перед «зелёным».

## Assumptions

- Модель режима (flash-lite) ставит ударения в омографах по правилу промпта с полезной точностью — проверяется
  чтением FR-010; если нет — модель режима выбирает владелец.
- Записи словаря, встречающиеся в блоке, укладываются в бюджет секции системного промпта перевода (механизм 063).
