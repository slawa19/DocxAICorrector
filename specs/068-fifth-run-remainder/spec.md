## Requirements *(mandatory)*

- **FR-001 (X-1)**: по механизму из обследования A — форма, которая не даёт блоку из многих абзацев-ячеек терять и
  удваивать записи (кандидаты, замеряются, не предрешены: детектор одинакового нормализованного текста под двумя
  маркерами при разных источниках → повтор; группировка смежных ячеек одного ряда/колонки в один фрагмент вызова с
  обратным разбиением; политика аппарата для раздела `index`); реплей указателя RM пятого прогона — дублей 0, потерь 0;
  ложные заголовки указателя 8 → ≤ 4; инварианты 063–067 держатся.
- **FR-002 (X-2)**: события пайплайна в прогоне раннера доходят до лога прогона: подменённый `log_event` пересылает
  каждое событие в логгер `docxaicorrector` (а значит в `<artifact_dir>/app.log`), отчёт сохраняет полный список
  событий (sidecar JSONL в каталоге артефактов или снятие капа 25 — по объёму из обследования B); причина отсутствия
  `config_key_ignored` устраняется; `docs/LOGGING_AND_ARTIFACT_RETENTION.md` §1.1 описывает маршрут. Замер: на
  реплее/стаб-прогоне раннера `block_apparatus_kept_by_model` виден в `app.log`, число совпадает со счётчиком.
- **FR-003 (X-3)**: склейка FR-005 067 допускает страницу без строк тела, когда обе половины — серия примечаний в теле
  одного кегля (форма FR-001 067) и остальные условия (последняя/первая строка, «нет места», кегли равны, не закрыт)
  выполнены. Замер на размеченном наборе 067 B: Money `p0389`, `p0810` склеены; 32/32 при 0 ложных или названный
  остаток; инварианты держатся.
- **FR-004 (X-4)**: 17 файлов храповика и перечисленные фрагменты основного текста переписываются синтетическим
  текстом той же формы (длина, регистр, пунктуация, цифры); `_PENDING_OWNER_DECISION` пуст и удаляется; URL
  `block_execution.py:268` заменяется формой; тест, упавший на синтетике, НЕ подгоняется — записывается как признак
  подогнанного правила. Гард без списка — зелёный.
- **FR-005 (замер)**: адресный платный прогон RM (≈ $0,5) после FR-001: дублей и потерь в указателе 0, ложных
  заголовков указателя ≤ 4, события блока в `app.log` прогона.

## Success Criteria *(mandatory)*

- **SC-001**: офлайн-реплей указателя RM пятого прогона — дублей 0, потерь 0; ложных заголовков указателя ≤ 4.
- **SC-002**: стаб-прогон раннера — события блока в `app.log` прогона, число равно счётчику; `config_key_ignored`
  видно, когда есть что игнорировать.
- **SC-003**: размеченный набор разрывов — 32/32 при 0 ложных, или остаток назван.
- **SC-004**: гард корпусных фраз зелёный без `_PENDING_OWNER_DECISION`; ни один тест не подогнан.
- **SC-005**: полный прогон зелёный; приёмочное ревью Codex по всем затронутым поверхностям до слияния в `main`.
- **SC-006** (FR-005): указатель RM на платном прогоне — 0 дублей, 0 потерь.

## Non-goals

- Не чинить Box 7.1 группы 2–3 (X-5): сигнала ряда в источнике нет, единственное правило-кандидат вредит указателю RM.
- Не переводить указатель по-другому (правило 12 и D1 063 не трогаются): FR-001 — про целостность доставки, не про
  язык записей.
- Не вводить словари и литералы книг — ни в код, ни в тесты (066, 067 P6).
- Не запускать полный прогон четырёх книг: FR-005 — одна книга, адресно.

## Anti-regression

1. Инварианты 063–067 (числа, маркеры, заголовки уровней 1–2, 45/45, склейки ячеек 0, разрывы 29/32→32/32)
   пересчитываются после FR-001 и FR-003.
2. FR-002: UI-путь логирования (`.run/app.log`, ротация) не меняется; тесты `test_logger.py`, раннера.
3. FR-004: каждый переписанный тест проходит на синтетике без изменения утверждений.
4. Полный прогон в главном дереве и `git status --porcelain` пуст перед «зелёным»; ревью Codex перед слиянием.
